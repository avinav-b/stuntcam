Get started

# arm the booted simulator
$ npx stuntcam up
self-test passed · armed iPhone 17 Pro (iOS 27.0)
# then run your app as usual
$ npx expo run:ios
# change the picture any time
$ npx stuntcam source qr:'https://stuntcam.dev'

Install and run

React Native / Expo
npx stuntcam up, then npx expo run:ios
Xcode
npx stuntcam up --udid <simulator> with the simulator shut down (or npx stuntcam up --reboot if it is already booted), then Run (⌘R) in Xcode as usual
Flutter
npx stuntcam up, then flutter run
Tests & CI
npx stuntcam up --udid $SIM --grant com.example.app, then npx stuntcam exec -- xcodebuild test -scheme MyApp -destination "platform=iOS Simulator,id=$SIM"
Use your own picture
npx stuntcam source image:/path/photo.png (or video:/path/clip.mov)
Show a QR code
npx stuntcam source qr:'https://example.com'
Turn it off
npx stuntcam down (no reboot)
Camera not showing?
npx stuntcam doctor
